# Approval Policy

## L0 — Autonomous
Read code/docs, inspect architecture, create proposals, write tests/docs, modify sandbox/work branches, run tests/lint/security scans, prepare pull requests.

## L1 — Review Recommended
Dependency upgrades, non-breaking API changes, schema additions, staging deployments, moderate refactors.

## L2 — Explicit Approval
Production deployment, breaking API changes, significant architecture changes, production database migrations, auth/authorization changes, major infrastructure changes.

## L3 — Explicit Authorization / Prohibited by Default
Destructive production data actions, credential exposure, bypassing security, financial transfers, disabling critical controls, deleting core infrastructure, unauthorized external communications.
